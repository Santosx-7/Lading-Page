# 🌐 Landing Page Empresarial
Template de site empresarial moderno e responsivo, com múltiplas páginas e tema escuro.
# 📋 Sobre o Projeto
Landing page completa desenvolvida com HTML, CSS e JavaScript puro. O projeto conta com 4 páginas interligadas, design responsivo, paleta de cores escura com destaque em azul-petróleo e botão de alternância de tema.
# 📄 Páginas

Home (index.html) — hero section com apresentação e cards de serviços
Sobre (sobre.html) — missão, visão, valores, estatísticas, equipe e timeline
Contato (contato.html) — formulário de contato e informações de e-mail
Login (login.html) — tela de autenticação com usuário e senha

# ✨ Funcionalidades

🎨 Design responsivo adaptado para desktop e mobile
🌙 Botão de tema escuro/claro na navbar
🧭 Navegação entre páginas com navbar fixa
📊 Seção de estatísticas com animação hover
👥 Seção de equipe com cards interativos
🕐 Timeline da história da empresa
📬 Formulário de contato
🔐 Tela de login com "lembrar senha" e "esqueci a senha"

# 🚀 Tecnologias Utilizadas

HTML5
CSS3 (Flexbox, media queries, animações)
JavaScript (Vanilla)
Font Awesome 6.5 — ícones
Google Fonts — fontes Poppins e Boldonse
